# 🌟 메이플스토리 스타포스 강화 비용 분석기

### 👉 [사이트 바로가기](https://asdf234a.github.io/maple-starforce-analyzer/)

설치 없이 브라우저에서 바로 쓸 수 있습니다. PC와 모바일 모두 됩니다.

"22성까지 평균 얼마 들까?", "운이 나쁘면 얼마까지 각오해야 하지?", "대장장이한테 맡기는 게 나을까?"
장비를 넣으면 이런 질문에 숫자로 답해 주는 계산기입니다. 장비 여러 개를 한꺼번에 강화할 때의 총비용도 계산할 수 있습니다.

---

## 무엇을 알려주나요?

- **평균 강화 비용 (기댓값)**: 같은 강화를 아주 많이 반복했을 때의 평균 비용
- **운에 따른 비용 범위**: 운이 좋은 상위 10%는 얼마에 끝나는지, 운이 나쁜 경우엔 얼마까지 드는지
- **추천 강화 방법**: 성수마다 파괴방지, 확정복구, 12성부터 다시(롤백) 중 평균 비용이 가장 싼 방법을 자동으로 골라 줍니다
- **대장장이 가격과 직작 승률**: 대장장이 가격(평균 비용 × 배율)과, 직접 강화했을 때 그 가격 안에 끝낼 확률
- **예상 파괴 횟수**: 평균 몇 번 터지는지, 한 번도 안 터질 확률은 얼마인지

## 사용 방법

### 1. 강화 조건 고르기 (왼쪽 "강화 조건 및 혜택 설정")

| 항목 | 설명 |
|---|---|
| 샤이닝 스타포스 | 이벤트 기간이면 켜세요. 비용 30% 할인, 21성 이하 파괴 확률 30% 감소, 흔적 복구 메소 20% 할인이 적용됩니다. |
| MVP 등급 할인 | 실버 3% / 골드 5% / 다이아 10% (17성 미만 강화에만 적용) |
| 프리미엄 PC방 할인 | PC방이면 켜세요. 5% 추가 할인 (17성 미만 강화에만 적용) |
| 대장장이 배율 | 대장장이 가격을 "평균 비용의 몇 배"로 볼지 정합니다. 1.05 / 1.08 / 1.10 / 1.15배 버튼으로 고르거나 직접 입력하세요. 기본값은 1.08배입니다. |

### 2. 장비 추가하기 ("장비 추가" 버튼)

| 입력칸 | 설명 |
|---|---|
| 장비 레벨 | 위쪽 버튼(250제, 200제, 160제 …)을 누르면 자동으로 채워집니다. |
| 장비 이름 | 알아보기 쉬운 이름을 적으세요. 예: 몽환의 벨트 |
| 시작 성수 / 목표 성수 | 지금 몇 성이고 몇 성까지 올릴지 적습니다. 최대 30성까지 됩니다. |
| 노작 장비 가격 | 파괴됐을 때 복구에 쓸 같은 장비(노작) 한 개의 가격입니다. **만 메소 단위**로 입력합니다. |
| 수량 | 같은 장비를 몇 개 강화할지 적습니다. 예: 반지 2개 |

> 💡 **노작 가격은 만 메소 단위입니다.**
> `32` → 32만 메소 · `150000` → 15억 메소 · `400000` → 40억 메소

장비를 저장하면 바로 결과가 계산됩니다. 목록의 연필 버튼으로 수정하고, 휴지통 버튼으로 삭제할 수 있습니다.

## 결과 읽는 법

### 요약 카드

| 카드 | 뜻 |
|---|---|
| 총 기대 비용 (평균) | 평균적으로 드는 비용입니다. 강화 메소와 복구 비용(노작, 복구 메소)을 모두 합친 금액입니다. |
| 중앙값 (상위 50%) | 절반의 사람은 이 금액 안에 끝냅니다. 보통 평균보다 낮습니다. 아래 자주 묻는 질문을 참고하세요. |
| 대장장이 가격 | 평균 비용 × 대장장이 배율입니다. **직작 승률**은 직접 강화했을 때 이 금액 이하로 끝날 확률입니다. |
| 상위 10% ~ 90% 예산 범위 | 10명 중 8명은 이 범위 안에서 끝납니다. 오른쪽 금액(90%)을 넉넉한 예산으로 잡으면 됩니다. |
| 예상 소모 장비 | 평균적으로 필요한 노작 장비 개수와, 한 번도 안 터지고 끝날 확률입니다. |

### 장비별 표

- **추천 전략**
  - 🛡️ 파방: 그 성수에서는 파괴방지를 켜는 게 이득입니다.
  - ✨ 확정복구: 파괴되면 확정복구로 같은 성수로 되돌리는 게 이득입니다.
  - 🔄 12성 롤백: 파괴되면 노작 1개로 12성부터 다시 올리는 게 이득입니다.
- **대장장이**: 장비 하나하나의 대장장이 가격과 직작 승률입니다.
- **평균 파괴**: "N개"는 필요한 노작 장비 개수, "파괴 N회"는 터지는 횟수입니다. 확정복구는 한 번 터질 때 노작을 여러 개 쓰기도 해서 두 숫자가 다를 수 있습니다.

### 백분위 표와 그래프

- **백분위 표**: "상위 X%"는 운이 좋은 순서로 줄 세웠을 때 X% 지점의 비용입니다. 예를 들어 "상위 90%"는 10명 중 9명이 이 금액 안에 끝낸다는 뜻입니다.
- **비용 분포 그래프**: 비용별로 끝날 확률(막대)과, 그 금액까지 끝날 누적 확률(선)을 보여 줍니다.
- **파괴 횟수 그래프**: 장비가 몇 개 터질지의 확률입니다.

## 편의 기능

- **내 커스텀 프리셋**: 자주 계산하는 장비 목록을 "현재 목록 저장"으로 저장해 두고, 다음에 한 번에 불러올 수 있습니다. 칩의 ✕를 누르면 지워집니다.
- **텍스트 복사**: 결과 요약을 복사해서 디스코드나 단톡방에 바로 붙여 넣을 수 있습니다.
- **CSV 다운로드**: 엑셀에서 열 수 있는 표 파일로 저장합니다.
- **JSON 저장**: 설정과 결과 전체를 파일로 저장합니다.

> 프리셋과 대장장이 배율은 **지금 쓰는 브라우저에만** 저장됩니다. 다른 기기나 다른 브라우저에서는 보이지 않고, 인터넷 사용 기록을 지우면 사라질 수 있습니다.

## 계산 기준

- 현재 스타포스 규칙 기준입니다. 강화 실패 시 하락하지 않고, 스타캐치 성공은 항상 포함해서 계산합니다.
- **파괴방지**는 15~17성에서만 쓸 수 있습니다. 파괴방지 추가 비용(기본 비용의 2배)에는 할인이 적용되지 않습니다.
- **파괴 시 복구**
  - 12성 롤백: 노작 1개를 써서 12성부터 다시 올립니다.
  - 확정복구: 노작과 복구 메소를 써서 파괴된 성수 그대로 되돌립니다. 23성 이상에서 파괴되면 22성으로 복구됩니다.

    | 파괴된 성수 | 필요한 노작 |
    |---|---|
    | 15~18성 | 1개 |
    | 19~20성 | 2개 |
    | 21성 | 3개 |
    | 22성 이상 | 4개 |

  - 확정복구 메소는 장비 레벨마다 다릅니다. 복구 비용 정보가 있는 레벨(140·145·150·160·200·250제, 130·135제는 19성까지)만 확정복구를 계산하고, 그 외 레벨은 12성 롤백으로만 계산합니다.
- 평균 비용 계산 방식은 [STARFORCE.GG의 기대값 계산 로직](https://starforce.gg/blog/ev-calculation-logic)과 같습니다.

## 자주 묻는 질문

**Q. 평균(기댓값)이 중앙값보다 훨씬 높은데 왜 그런가요?**
대부분은 평균보다 적게 쓰고 끝나지만, 드물게 여러 번 연속으로 터지는 사람이 아주 큰 금액을 씁니다. 이 소수가 평균을 끌어올려서 평균이 중앙값보다 높아집니다.

**Q. 새로고침할 때마다 중앙값이나 직작 승률이 조금씩 바뀌어요.**
평균 비용과 평균 파괴 횟수는 공식으로 정확히 계산해서 항상 같습니다. 반면 운에 따른 범위(백분위, 그래프, 직작 승률)는 강화를 수만 번 가상으로 돌려서 구하기 때문에, 계산할 때마다 아주 조금씩 달라집니다(보통 1% 이내).

**Q. 노작 가격에는 뭘 넣어야 하나요?**
파괴됐을 때 복구 재료로 쓸 같은 장비 한 개를 구하는 비용을 넣으세요. 경매장 시세를 넣거나, 직접 파밍한다면 그만큼의 가치를 넣으면 됩니다. 노작 가격에 따라 추천 강화 방법(파괴방지, 확정복구, 12성 롤백)도 달라집니다.

**Q. 사이트가 업데이트됐다는데 예전 화면이 보여요.**
`Ctrl + Shift + R`(맥은 `Cmd + Shift + R`)로 강력 새로고침을 해 보세요. 모바일은 시크릿 창으로 열어 보세요.
