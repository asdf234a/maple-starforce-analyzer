# 메이플스토리 스타포스 다중 분석기 (Maple Starforce Multi-Analyzer)

메이플스토리 스타포스 강화 비용 및 파괴 횟수의 확률 분포(PMF/CDF)를 FFT(고속 푸리에 변환) 합성곱 엔진으로 실시간 결합 분석하는 웹 애플리케이션입니다.

- **데이터 및 확률 공식**: [mesulive (kurateh/mesulive)](https://github.com/kurateh/mesulive) 100% 동일 구현
- **강화 최적화(DP) 엔진**: [starforce.gg](https://starforce.gg)의 Bellman Equation 기반 최소 비용 파방/복구 자동 최적화 알고리즘 탑재
- **대장장이 가격 분석**: 기댓값 1.08배 가격의 누적 확률분포(CDF) 백분위수 및 직작 승률 분석

---

## 주요 기능

1. **다중 아이템 결합 분석**:
   - 칠흑 5세트, 에테르넬 4세트, 아케인 5세트 등 여러 부위를 동시에 강화할 때의 총합 비용 분포와 파괴수 분포를 0.2초 내 산출
2. **강화 경로 자동 최적화 (DP)**:
   - 장비 레벨 및 노작 가격에 맞춰 최소 비용 경로(15~17성 파방, 15~22성 확정복구 vs 12성 롤백)를 자동으로 탐색하여 적용
3. **대장장이 가격 비교**:
   - 기댓값의 1.08배 가격 및 직작 성공 승률 분석
4. **결과 내보내기**:
   - 📋 텍스트 리포트 복사 (인벤/디스코드용)
   - 📊 CSV 엑셀 다운로드
   - 📁 JSON 데이터 다운로드
